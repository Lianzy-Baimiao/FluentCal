# 全面 Alpha（Windows 0.3.22 / Android 0.3.7）

用户要求先发布值得做的改进，再完成全面 Alpha。0.3.19 已公开发布，以下是第二阶段的颜色约定。

- 色值支持 `#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`，末尾 AA 是不透明度（00 全透明、FF 不透明）；保存统一为大写长格式。已有不透明色、预设名称、auto/system 保持原行为。
- Windows 色盘显示“不透明度”百分比和棋盘格预览，调整 HSV/RGB 不丢失 Alpha；只有确认才保存。任务、分组、日期颜色及各外观颜色均能选自定义透明色。
- 日历背景色 Alpha 与现有“背景透明度”“单元格透明度”分别相乘，避免两个设置互相覆盖；背景相关边框/阴影按最终背景不透明度缩放。休息日底色、日期标记、今日底色继续保留既有显示强度并乘入色值 Alpha。浮窗保持最低可读背景，不跟着变成不可读的全透明面板。
- 任务/分组条保留 Alpha，文字保持可读，不把整个控件连同文字一起透明化。文字颜色按当前主题底色合成后选择；桌面壁纸是任意图片，不能对所有壁纸保证固定对比度，现有文字阴影功能继续可用。
- 强调色的填充保留 Alpha；用于链接、图标的强调文字保持不透明并按当前主题背景调整，防止低 Alpha 使操作入口消失。
- 网页保持只读，跟随桌面展示 Alpha，不新增颜色编辑入口。安卓任务编辑器提供自定义颜色、HEX 输入和不透明度滑块，甘特条与桌面使用相同色值；编辑其他字段时保留原色值。
- JSON/同步原样保留八位色值，MCP 接受新格式，SVG/PNG 导出保留颜色 Alpha。已有数据不重写。旧客户端可能把八位自定义色显示为默认颜色，使用透明色时建议更新到 Windows 0.3.22 / Android 0.3.7。
- 验收：已知 RGBA 合成值、透明度相乘、0/50/100% 边界、HSV/RGB 保留 Alpha、取消不保存、深浅色文字、JSON 往返、MCP、网页/安卓、导出与旧设置基线。
