# FluentCal 0.3.24

## What's new

- In All, find monthly to-dos and no-date tasks in separate sections. Completed flexible tasks appear on their actual completion dates, and today's heading shows the full date.
- Keep the undated-section jump controls visible while scrolling long lists.
- Selecting a countdown in the expanded list now opens its date.
- Set today's calendar highlight with independent RGBA border color, width and fill. Existing highlight settings migrate automatically.
